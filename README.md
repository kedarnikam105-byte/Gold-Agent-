# AURA Multi-Agent Gold v2
Upload all files to the repository root and deploy `streamlit_app.py`. Add `TWELVE_DATA_API_KEY` in Streamlit Secrets. The News agent explicitly reports unavailable until a licensed news API is integrated. This app is educational and does not execute trades.

## Agent roster
- Mike: Supervisor and Team Lead
- Jarvis: Momentum Analyst
- Tom: Trend Analyst
- Criss: Risk and Volatility Analyst
- KD: Chart Pattern Analyst
- Harry: News and Macro Analyst

These are fictional interface names used for the application agents.
